fix(mobile): 手机端点进聊天白屏 + 建议卡显示 [object Object]

白屏原因：
- 之前修空态时加过 .w4-main { position: relative; width: 100% }（全局，无媒体查询）
- 它与移动端 .w4-main { position:absolute; inset:0 } 同优先级但更靠后
- 手机上主内容列退化成 flex 子项，被 width:100% 的列表列挤成 0 宽并推到屏幕外
- 实测点进聊天：.w4-main {x:390, w:0} → 视觉上全白

修法：在 w4-part2.css 末尾用 @media (max-width: 899.98px) 重新声明移动端规则
（absolute + inset:0 + translateX，data-mobile-view="main" 时归位）

同时修：
- 后端 message.suggestion 是对象（better_version / explanation / tag / is_saved），
  之前直接 String() → 界面显示 "[object Object]"，现已按字段映射，
  tag grammar → 语法；保存状态读 is_saved

- 桌面 1280：.w4-main {x:492,w:788}，无回归
