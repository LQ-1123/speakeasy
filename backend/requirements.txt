# 重要：本文件**不包含 torch**。PyTorch 必须按 CUDA 版本单独安装，

#   1) py -3.11 -m venv .venv
#   2) .venv\Scripts\activate
#   3) pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu128
#   4) pip install -r backend/requirements.txt
#
# RTX 5080 是 Blackwell 架构（compute capability 12.0），
# **必须** CUDA 12.8+ 的 torch（>= 2.7）。CUDA 12.1/12.4 的轮子不含 sm_120 kernel，
# 装了也跑不起来（会报 "no kernel image is available for execution on the device"）。
