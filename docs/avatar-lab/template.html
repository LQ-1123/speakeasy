Avatar Lab · 种子驱动 · 完全离线

头像生成技术对比

同一个种子，不同技术画出来的「人」。本页包含 31 种 DiceBear 画风（含 Avataaars）与 6 种非 DiceBear 的算法头像（Identicon / Blockies / Jazzicon / Minidenticon / Boring Avatars / 本项目 SeedFace）。全部在浏览器本地生成，不请求任何外部服务；页面单文件，可直接双击打开。

同一 seed → 同一张脸；改一个字符就换一个人

一、DiceBear 全部画风

每张卡片左边是当前种子，右边三个是相邻种子（同 seed 永远同脸）

二、同一 seed × 不同技术

同一个「人」在不同风格下的样子

三、非 DiceBear 的算法头像

纯手写 SVG / Canvas 算法：钱包、GitHub、匿名社区的经典做法

四、人种 × 性别 × 年龄

本项目 SeedFace：五个地域 × 两种性别 × 三个年龄段（22 / 29 / 40 岁）
说明：插画只能表达「可识别的视觉线索」——人种靠肤色与发色/发质，性别靠发型、胡须、耳环、唇色， 年龄靠灰白发、眼角/法令纹、眼镜概率与发型偏好。DiceBear 与 Avataaars 没有年龄维度， 只能通过发色/配饰间接暗示；要做到接近真人的区分，仍需 AI 人像生成。

六、本项目现状与接入方式

SpeakEasy V3 已把 Persona 头像改为服务端种子生成
服务端只存 personas.avatar_seed（如 persona-jiwoo），头像由 GET /api/v3/avatar/{seed}.svg?g=female&r=east_asian 确定性生成； 信息流、主页、偶遇、聊天共用同一 URL。要换成上表中的任意方案，只需要替换这个 URL 的生成函数， 数据库不用改（种子不变 → 换技术后仍是「同一个人」，只是画风变了）。 
// 前端本地生成（DiceBear，和本页一样）
import { createAvatar } from "@dicebear/core";
import * as avataaars from "@dicebear/avataaars";
const svg = createAvatar(avataaars, { seed: "persona-jiwoo", size: 96 }).toString();

// 服务端种子接口（当前实现）
GET /api/v3/avatar/{seed}.svg?g=female&r=east_asian
→ image/svg+xml, Cache-Control: immutable
本页由 scripts/build_avatar_lab.py 生成：用 esbuild 把 DiceBear 31 种画风打包进单文件 HTML， 所有头像在浏览器本地渲染，无网络请求、无追踪。DiceBear 画风的作者与授权见 dicebear.com/styles。AI 生成人像本轮未接入。
