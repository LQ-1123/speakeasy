## 本版更新

- Admin → API 与密钥增加 Fish、Deepgram、OpenAI 兼容 LLM 和 SiliconFlow 的多账号资源管理。点击“＋添加账号”，配置凭据与真实配额，保存并验证成功后参与调度。
- HTTP 请求按配额组占用率和 EWMA 耗时分配；同账号的多把 Key 共用配额，同模型路由保持模型和角色音色。Deepgram 连接建立后固定绑定账号。
- 提供冷却、熔断、日/月请求预算、密钥加密、热更新与排空删除。保存条目没有业务固定数量上限；实际并发仍受上游额度、进程保护、内存和网络限制。
- 聊天、语音与后台任务使用有界调度；音频失败可单独重试，避免重复生成整轮回复。保留每用户任务约束与整轮期限，减少后台工作争抢前台资源。
- Android 打包当前静态客户端，沿用现有应用 ID 和签名，更新邮箱登录、号池管理和原生更新界面相关代码。README、部署、移动端、更新和容量文档同步审计。
