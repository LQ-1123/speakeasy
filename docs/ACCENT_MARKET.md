这套功能让你**自己决定**：说什么口音、扮演什么角色、在什么场景里练。

  -d '{"persona_id":"oliver","voice":""}'

## 二、自定义角色

点右上角 **➕ 造角色**。

### 填表就行

不用写 prompt。填这些字段，系统自动生成：

| 字段 | 说明 | 示例 |
|---|---|---|
| 名字 * | 角色叫什么 | Chidi |
| 性别 | 男 / 女 | 男 |
| 城市 | 住哪 | Berlin |
| 职业 | 干什么的 | 创始人 |
| **口音** | 从口音市场里选 | 🇳🇬 尼日利亚 男声·Abeo |
| 性格 | 逗号分隔 | 直接, 好奇, 要求高 |
| 说话风格 | | 说话快，喜欢追问细节和数据 |
| 开场白 | 第一句话 | Come in, sit down... |
| 场景 | 从场景模板选或选自定义场景 | 求职面试 |
| 难度 | 1–5 | 4 |
| 额外设定 | 可选 | 会说一点德语，偶尔夹德语词 |

点 **▶ 试听** 可以先用这些设定听一句开场白，再决定要不要保存。

### 生成的提示词长什么样

系统按模板生成，关键设计：

1. **口音用行为描述**（语速、用词、节奏），**绝不用假拼写**
   （写 "Roj" 冒充印度口音是错的，模型会念成真的 Roj）
2. **纠错用「重述」示范**，不直接指出错误
3. 每次回复 1–3 句，像真人闲聊
4. 不扮演老师，不写旁白

生成结果类似：

```
你是 Chidi。
你住在Berlin是一名创始人。
性格：直接、好奇、要求高。
说话风格：说话快，喜欢追问细节和数据
当前场景：这是一场求职面试... 地点：柏林一家初创公司...
额外设定：会说一点德语，偶尔夹德语词

【口语练习规则】
- 全程用英语对话。每次回复 1–3 句，像真人闲聊，不要长篇大论。
- 如果对方表达有语法或用词问题，用「重述」的方式自然示范正确说法，
  不要直接指出错误，也不要解释语法。
- 你会主动追问、给反应（惊讶、认同、好奇），让对话持续下去。
- 不要扮演老师，不要写旁白或动作描述（如 *smiles*）。
```

### 保存后

角色会出现在左侧角色列表里，带 `[自定义]` 标记，可以直接选它对话。

## 三、自定义场景

场景两个入口：

1. 造角色时的「场景」下拉 → 选模板或已建的自定义场景
2. 直接调 API（UI 里的场景管理器在下一步加）

### 内置场景模板（9 个）

| key | 场景 |
|---|---|
| `cafe` | 咖啡店点单 |
| `airport` | 机场值机 |
| `interview` | 求职面试 |
| `hospital` | 看医生 |
| `hotel` | 酒店入住 |
| `landlord` | 租房看房 |
| `phone` | 客服电话 |
| `networking` | 社交场合 |
| `custom` | 完全自定义 |

### 自定义场景 = 模板 + 你的细节

```json
{
  "name": "柏林创业公司面试",
  "template": "interview",
  "place": "柏林一家做气候科技的初创公司",
  "goal": "面试产品经理，要讲清楚一次从 0 到 1 的经历",
  "details": "对方是联合创始人，说话直接，会追问数据"
}
```

生成给 LLM 的场景描述：

> 这是一场求职面试。对方是面试官，会问你的经历和动机。 地点：柏林一家做气候科技的初创公司。 这次对话的目标：面试产品经理，要讲清楚一次从 0 到 1 的经历。 背景细节：对方是联合创始人，说话直接，会追问数据

## 四、API

### 口音市场

| Method | Path | 说明 |
|---|---|---|
| GET | `/api/market/summary` | 概览（总数/官方数/兜底数/地区数） |
| GET | `/api/market/regions` | 地区列表 |
| GET | `/api/market/accents` | 全量口音（`?kind=` `?locale=` 过滤） |
| POST | `/api/market/preview` | 试听任意声线（返回 wav） |
| POST | `/api/market/assign` | 给角色换口音（`voice: ""` = 恢复默认） |

### 自定义角色

| Method | Path | 说明 |
|---|---|---|
| GET | `/api/custom/personas` | 列表 |
| POST | `/api/custom/personas` | 新建/更新 |
| DELETE | `/api/custom/personas/{id}` | 删除 |
| POST | `/api/custom/personas/preview` | 用表单内容试听开场白 |

### 自定义场景

| Method | Path | 说明 |
|---|---|---|
| GET | `/api/custom/scene-templates` | 模板列表 |
| GET | `/api/custom/scenes` | 列表 |
| POST | `/api/custom/scenes` | 新建/更新 |
| DELETE | `/api/custom/scenes/{id}` | 删除 |

## 五、数据存储

| 文件 | 内容 |
|---|---|
| `data/custom.json` | 自定义角色、自定义场景、**口音覆盖** |
| `backend/app/personas/personas.json` | 内置角色（只读，升级不覆盖用户数据） |

`custom.json` 结构：

```json
{
  "personas": [...],
  "scenes": [...],
  "voice_overrides": {
    "oliver": "en-ZA-LukeNeural"
  }
}
```

**为什么分开存**：升级不丢用户数据；内置角色可以随时改进；用户只能改自己创建的。

## 六、口音解析优先级

`resolve_voice(persona_id)` 的顺序：

```
1. 自定义角色的声线（u_xxx）           ← 建角色时选的
2. 口音市场的覆盖（custom.json）        ← 市场里换的
3. 内置 PERSONA_VOICES 映射            ← 出厂默认
```

所以市场里换口音**立即生效**，不需要重启，也不污染内置配置文件。

## 七、已知限制

| 限制 | 说明 |
|---|---|
| 外语兜底发音可能不准 | 外语声线没学过英文，靠字母规则硬读 |
| 自定义场景暂无 UI | 目前只能通过 API 创建，UI 在下一步 |
| 口音不能"混合" | 一个角色一次只能用一种口音 |
| 自定义角色不能上传音色 | 想用自己的音色请用「🔊 克隆音色」绑定到角色 |
